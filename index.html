Stocks where the 9-day simple moving average crossed above the 20-day simple moving average today — a classic bullish "golden cross" day-trading signal. Each row shows the latest date, current volume, and closing prices for the last three trading days. The trend arrow is green when momentum is up and red when it turns down. Sort by any column using the control below (or the headers on wider screens).

Sort
How it works: a Python screener (screener.py) runs on GitHub Actions each weekday after the US close, scans the full US-listed universe (~10k+ symbols via NASDAQ Trader / SEC), computes the 9-day and 20-day SMAs, and writes signals.json with every stock that crossed up that day. This page loads that file. Until the first scan runs it falls back to a built-in sample set so the layout is always demonstrable. Educational tool, not financial advice.
